# Backend (Laravel)

This directory is reserved for the Laravel API.

## Setup Instructions

Run the following command in this directory to install Laravel 12.x:

```bash
composer create-project laravel/laravel .
```

## Recommended Dependencies

```bash
composer require filament/filament laravel/sanctum laravel/horizon
```

## Notes

- This folder is managed by Composer, not Bun.
- Ensure your `.env` is configured for API use.
